# Native terminal

Code's optional dock is a real pseudoterminal and terminal emulator, rather than a command-output scroller. It launches the user's existing shell in the active checkout on demand; opening Code does not launch a terminal process. It uses the Apache-2.0 licensed [Alacritty terminal engine](https://docs.rs/alacritty_terminal/0.26.0/alacritty_terminal/), version 0.26.0, for ANSI/VT parsing, cursor movement, colors, alternate screens, reflow, Unicode and selection. GPUI paints the visible screen using native text shaping; there is no WebView, xterm.js, JavaScript runtime or second application renderer.

The PTY and emulator live on one worker. Nonblocking IO and readiness polling sleep when idle. Visible frames coalesce at most once per 16 ms while output changes; hidden docks retain shell state but skip viewport projection and UI wakes. Screen dimensions are bounded to 240 columns by 80 rows; scrollback retains 2,000 rows, and only the current viewport is projected. Adjacent cells share style runs to avoid one shaping operation/allocation per character. Input reservations are bounded to 256 KiB and individual pastes to 64 KiB. Selection copies are bounded to 256 KiB. Oversized input is rejected explicitly.

Keyboard input includes terminal navigation/application-cursor mode, modified arrows, control/meta keys, function keys, IME composition, drag selection, scrollback, Cmd-C selection copying and Cmd-V pasting. Bracketed paste follows the terminal's negotiated mode. OSC52 clipboard read/write requests are disabled; output cannot silently read or replace the system clipboard. Terminal links are never executed. The emulator retains its native alternate-screen and cursor state. Sixel/Kitty graphics, terminal URL actions, remote terminals and full Kitty keyboard protocol are not implemented.

Resize sends TIOCSWINSZ to the real PTY. Stop and Close end the owned terminal session, including its terminal-session background groups, and reap the shell before reporting settlement. The root PID remains unreaped until cleanup finishes, preventing reuse during ownership checks. Close keeps the active-terminal guard until cleanup completes, so checkpoint restoration cannot race a closing shell. Independently daemonized/reparented processes and external services deliberately detached from the terminal are not claimed to be managed sessions. This dock uses normal local shell permissions, not an additional VM/container or agent sandbox; Codex's sandbox-backed `/terminal` remains a separate native provider operation.

Verification includes a disposable real PTY Unicode roundtrip, a real `stty size` resize, owned background-job teardown, byte-split ANSI/Unicode parsing, alternate-screen restore, bounded scrollback, output-wake coalescing and oversized input rejection. These tests do not launch authenticated models or install shells.

## Dependency and build impact

`alacritty_terminal` is pinned to 0.26.0 with default features disabled. Its addition resolved six new lockfile packages: the terminal engine, `vte`, `rustix-openpty`, `signal-hook`, `cursor-icon` and Windows-only `miow`. Most foundational dependencies were already present through GPUI. No Alacritty window, graphics renderer, executable or configuration watcher is started. The retained Apache license is in `LICENSES/Alacritty-Terminal-Apache-2.0.txt`. Runtime state/processes are allocated only when the terminal is opened. An isolated binary-size delta has not been measured; the release build also contains independent feature changes, so total bundle-size differences should not be attributed solely to this dependency.
